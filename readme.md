# Java Projects Portfolio

This repository contains Java projects I have worked on while building my skills in object-oriented programming, application design, and testing. Each project is kept in its own folder and may have its own setup instructions.

## Projects

### 1. Hotel Operations System
A Java project for practicing hotel operations and object-oriented programming.

- `Room`: tracks beds, price, occupancy, cleanliness, and availability.
- `Employee`: stores employee details, tracks hours worked, and calculates regular hours, overtime, and pay.
- Unit tests: uses JUnit to check room check-in/check-out and employee punch-in/punch-out behavior.

### 2. Clear Ledger
A Java ledger application for recording deposits and payments, viewing transactions, and generating reports. This project has command-line and graphical versions.

### 3. Online Store
A command-line store project for loading products, searching inventory, and managing a shopping cart.

### 4. Library Management
A Java project for tracking books and their availability, including checking books in and out.

## Getting Started

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the folder for the project you want to run in IntelliJ IDEA.
3. Select the appropriate JDK for that project.
4. Follow any setup instructions inside that project's folder.

## Running Tests

If a project uses Maven, run its tests from the project folder with:

```bash
mvn test
```

You can also run a JUnit test class directly in IntelliJ by clicking the green run icon beside the test class or test method.
